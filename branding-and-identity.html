The difference

A logo is not a brand. A system is.

Many businesses treat branding as a single visual asset. The result is inconsistent application, mixed messages, and a presence that never settles into something recognisable.

We treat identity as a practical system: clear positioning, a coherent visual language, and simple rules that make consistent application possible across website, social media, and everyday materials.

The work is useful only if it can be followed. Guidelines are written to be used, not filed away.

Positioning before visuals We clarify what the brand stands for and who it speaks to before designing marks, colours, or type. Visual decisions follow direction, not the reverse.
Systems over single assets A logo alone is rarely enough. We build a workable set of elements - mark, colour, type, and usage rules - that can be applied consistently.
Guidelines that get used Documentation is kept practical. The aim is clarity for anyone applying the brand, not a thick book that never leaves a folder.
Two layers

Strategy and visual system work together

One without the other leaves gaps. Positioning without a clear visual language remains abstract. A visual system without direction becomes decoration.

Positioning

What the brand stands for and who it serves

Clear statements of purpose, audience, and tone. This becomes the reference for every visual and verbal decision that follows.

  • Audience and competitive context
  • Core positioning and personality
  • Tone of voice direction
Visual identity

The system that makes the brand recognisable

Logo, colour, typography, and supporting elements organised so they can be applied consistently across different media and formats.

  • Primary and secondary marks
  • Colour palette and type hierarchy
  • Usage rules and basic applications
Scope

What a branding project typically includes

The exact deliverables depend on whether you are starting from zero or refining an existing presence. Scope is defined clearly at the outset.

01

Discovery and positioning

We review the current state of the brand, clarify audience and goals, and establish a clear direction before any visual work begins.

02

Logo and mark development

Exploration of primary marks and supporting lockups. Concepts are refined until a clear, usable direction is selected.

03

Colour and typography

A practical palette and type system that supports hierarchy and remains readable across digital and print applications.

04

Supporting elements

Additional components such as patterns, icon style, or photography direction where they strengthen consistency.

05

Brand guidelines

Clear rules for logo use, colour, type, and spacing. Written so the brand can be applied correctly by designers, developers, or internal teams.

06

Basic applications

Key examples - website header, social profile, business card, or presentation cover - so the system is demonstrated in real contexts.

Process

How a branding project typically progresses

Clear stages and decision points. Progress depends on timely feedback and a willingness to lock direction once a strong option is identified.

Stage 1

Discover and define

  • Current brand review
  • Audience and positioning work
  • Direction and mood defined
  • Scope and deliverables confirmed
Stage 2

Design and refine

  • Logo and mark concepts
  • Colour and type exploration
  • System development
  • Revisions based on feedback
Stage 3

Finalise and deliver

  • Final logo system
  • Guidelines completed
  • Key applications prepared
  • Files and assets handed over
Fit

Who this is for and who should wait

This works if you

  • Need a clear and consistent visual identity
  • Are ready to make decisions on direction without endless options
  • Want guidelines that can actually be followed
  • Value coherence across website, social, and everyday materials

Skip this if you

  • Only need a single logo file with no system around it
  • Cannot decide on brand direction or personality
  • Want unlimited concepts without locking a direction
  • Expect branding alone to fix an unclear offer or weak product
